# 2026-11-27 開発記録

Ubuntu 24.04 / ROS 2 Jazzy上で、カメラと2D LiDARを使うボール外部較正の実装と操作性の改善を進めた。既存のカメラ・LD03ドライバーを再利用し、較正処理からモーターの制御や移動指令の送信は行っていない。

## 今日できるようになったこと

### ボールを使うカメラ・LiDAR外部較正

独立した `real/src/camera_lidar_calibration/` パッケージを追加した。

- カメラ画像、CameraInfo、LaserScanを受信し、画像と点群を専用GUIに表示。
- HSV・形状による画像上の球候補の抽出と、クリックによる対象選択。
- LiDARの隣接点クラスタリングと既知半径の円フィットによる球中心推定。球中心と走査面の高さ差も補正。
- 時刻差・静止・フィット誤差・重複位置を確認して、手動または自動で対応サンプルを取得。
- 平面PnPとロバスト最適化による6自由度の推定。学習用と独立検証用のサンプルを分離し、再投影誤差と分布を検査。
- サンプル・内部較正・外部較正結果をYAMLに保存し、再読込とオフライン再計算。
- 有効な結果による画像へのLiDAR点投影、点群、球位置・距離・検出状態の配信。
- TFの変換方向を検証し、競合監査後の明示操作でのみTFを配信。
- Control Centerから較正GUIと投影ノードを起動。

### サンプル取得とLiDAR表示の改善

静止時間・LiDAR許容幅・画像許容幅を、取得済みサンプルを保持したまま調整できるようにした。短い検出欠落には履歴を保持しつつ、現在の対象が見えないときの取得は拒否する。取得不可の理由と揺れ幅を表示する。

カメラの切断や内部較正待ちでLiDAR点群まで消える問題を修正した。LiDARの受信状態と球候補の検出状態を分けて表示する。実機では5秒間に50スキャンの受信を確認した。

点群画面では黄色が球候補、水色が選択中、緑が取得済み学習点、ピンクが検証点。候補1個は自動選択し、複数候補はクリックで選択する。黄色から緑への変化を待つ操作は不要。

### カメラ認識と撮影範囲の改善

このPCの赤色ボールに合わせてHSVの色相範囲を調整し、小さい赤い物体が同時に映るときも、候補の面積差や追跡条件で対象を選べるようにした。GUIで色をクリックして調整し、抽出マスクも確認できる。設定は既存のボール認識ノードにも再起動後に利用できる。

WCMカメラの対応モードを調査し、1280×720で640×480より横方向に広く映ることを確認した。撮影解像度の選択、解像度ごとの内部較正の保存、別GUIで変更した設定の再読込を追加した。以前の640×480用較正は保持する。

実機の認識比較では、調整前は68フレーム中11フレーム、調整後の広角モードでは67フレーム中67フレームで対象選択を確認した。同一条件の厳密なベンチマークではなく、その場の映像による確認であり、全環境での精度保証ではない。

## 現在の較正の進み具合

`extrinsic_2.yaml` の確認時点では、1280×720の内部較正と6点の対応サンプル（学習5点・検証1点）が保存されている。外部較正結果は `result: null` で、外部変換の推定はまだ完了していない。

現設定では学習12点以上・検証4点以上が必要。近距離・遠距離・左右から20〜25点程度を取得し、「外部較正実行」後に有効性を確認して再保存する。ファイル名だけで較正成功と判断しない。現在のファイルをTFや投影には適用できない。

PC固有のデバイス名、内部較正、取得データ、実測結果はユーザー設定ディレクトリに保持し、共有初期設定から分離している。今回のGit登録に個人用設定ファイルは含めない。

## 起動方法

リポジトリのルートから実行する。

```bash
source /opt/ros/jazzy/setup.bash
colcon build --base-paths real/src --packages-select camera_lidar_calibration --symlink-install
source install/setup.bash
export ROS_DOMAIN_ID=53
export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST
ros2 launch camera_lidar_calibration calibration.launch.py
```

カメラとLiDARは先に起動する。Control Centerの「カメラ・LiDAR 外部較正」では依存順に起動できる。有効な外部較正結果の保存後は次で投影する。

```bash
ros2 launch camera_lidar_calibration projection.launch.py
```

詳細は[外部較正README](../real/src/camera_lidar_calibration/README.md)、起動管理は[Control Center README](../ros2_control_center/README.md)を参照。

## 今回Gitに登録する周辺機能

未登録だったControl Center本体とGazeboシミュレーションも、関連する説明とともに登録する。Control Centerには起動停止・ログ・CANのUP操作・PS4手動操作・内部較正・自動接近の起動処理がある。Gazebo側には簡易機体、競技フィールド、仮想センサー、速度指令の監視がある。これらの機能をすべて今日の実機で再検証したという意味ではない。

## 今回実行した確認

- 較正パッケージのpytest: 18件成功、1件スキップ。スキップはシステムPythonにPySide6がないためのGUIテスト。
- 既存PySide6仮想環境でGUIテスト: 1件成功。
- パッケージのcolconビルド、Control Centerのハードウェアなしデモテスト、Python構文・シェル構文・差分検査に成功。
- カメラ設定テスト: 解像度別較正の保持と別プロセスの設定再読込に成功。
- 合成データのROSテストには、既知変換の推定、保存・読込、投影、検出喪失、TF方向・競合拒否、カメラ不在時のLiDAR表示を含む。

## 残っている確認

実物の球を広範囲に動かした外部較正の完了、独立位置での誤差評価、取り付け変更後の再較正、実機TFへの適用は未確認。外部較正を使った自動回収や100 mmまでの移動は今回の較正実装の対象外。別PCでの再現と照明・距離の変化に対する認識評価も必要。
