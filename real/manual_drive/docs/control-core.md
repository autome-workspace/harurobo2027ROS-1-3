# 非駆動の制御コア

接続先 PC でビルド・単体テストする C++ ヘッダー。CAN 送信・ROS の速度指令購読に接続していない。ハードウェアや走行の受入合格を意味しない。

## 4輪運動学

`wheel_kinematics.hpp` は輪ごとに中心座標 [m]、正方向の駆動単位ベクトル、半径 [m]、上限 [rad/s] を受け取る。逆運動学行列のランク3を確認し、上限超過は全輪を同率に縮小する。モーターの符号・減速比は含めない。ゼロ・並進・旋回・半径換算・飽和・特異配置をテスト済み。

テスト内の配置・半径は人工的な検証用であり、機体の測定値ではない。実機図との符号照合と測定値が揃うまで機体 YAML の値として使わない。

## ヨー保持

`heading_hold.hpp` は手動旋回優先。旋回入力ゼロかつ平行移動中、gyro_z の絶対値が 0.05 rad/s 以下で200 ms 続いたところで現在 yaw を捕捉する。角度差をラップし `Kp * error - Kd * gyro_z` を制限して返す。中立・許可解除では目標破棄・ゼロ出力。IMU 異常では healthy=false とゼロを返す。呼出し側はこの異常を保持し、正常サンプルが戻っただけで駆動を再許可しないこと。

この層は時刻・TF・quaternion・IMU のサンプル年齢を検証しない。それらは ROS 入力境界で検証する。IMU の実機ドライバ接続とゲイン調整は未実施。

## 残件

- 走行用に原子的な指令・許可・世代管理と受信監視を設計する。`/manual/armed` を単独で駆動許可に使わない。
- 通常加速度制限、CAN 返信の型別デコード、電流/温度/速度検証、機体パラメータ検証を接続する。
- TIMEOUT の意味と単位、通信断停止・停止距離は未確認。手動非常停止は用意済みだが、PC ハートビートによる自動遮断ではない。床上走行へ進む条件と分離して記録する。
