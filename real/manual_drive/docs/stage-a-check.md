# 段階 A：DS4 USB 実機受入

モーター、駆動電源、USB-CAN は接続しない。最初は DS4 以外のゲームコントローラーを外す。起動はリポジトリの README を参照。別端末でも同じ ROS 環境・ドメイン設定を使う。

```bash
ros2 topic echo /joy
ros2 topic echo /manual/armed
ros2 topic echo /cmd_vel/manual
```

1. 起動時は非許可、指令ゼロ。L1 押下やスティック偏位を保持したまま初期接続しても許可されない。
2. 中立・L1 解放の後、L1 を押すと許可される。左上で `linear.x > 0`、左左で `linear.y > 0`、右左で `angular.z > 0`。逆操作は各値が負。斜めでも並進の大きさは 0.25 m/s 以下。中立時はゼロ。
3. スティックを倒したまま L1 を離すと次の制御周期で非許可・ゼロになる。倒したまま L1 を押し直しても復帰しない。
4. L1 と前進を保持したまま DS4 の USB を抜く。`/joy` の最後のメッセージから非許可・ゼロまでと、USB 抜去から停止指令までを区別して記録する。入力消失からの停止指令の目標は 250 ms 以内。Joy が古い入力を再発行し続けた場合は不合格とし、接続監視を追加するまで次段階へ進まない。
5. L1 を保持したまま再接続しても非許可・ゼロを維持する。中立・L1 解放→押し直しでのみ復帰する。

記録：DS4 USB ID、軸・ボタンと符号、L1 解放・USB 抜去・再接続時の結果、停止指令までの時間、計測方法。ここで確認するのは停止**指令**であり、車輪の物理停止ではない。
